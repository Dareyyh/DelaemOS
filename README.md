# DelaemOS — MVP Кибернетической Операционной Системы (Пилот для 2–3 человек и подачи на грант)

Данный репозиторий содержит полностью рабочий исходный код MVP проекта **DelaemOS** с архитектурой **Главного Агента (Мета-Оркестратора)**, который самостоятельно обращается к математическому ядру, графу метрик (5 контуров, 17 полей паспорта), базе доказательных интервенций *HowToLiveBetter*, модулю стратегирования по 6 капиталам и командному контуру *Zero-Knowledge Privacy*.

---

## 1. Архитектура проекта и состав модулей

* `config.py` — Онтологическое ядро: 5 контуров человека, 6 капиталов стратегирования, стартовый каталог паспортов метрик (17 полей шаблона), пороги шлюзов $SGI$ и системный промпт ИИ-Штурмана.
* `database.py` — Реляционно-графовое хранилище на базе `SQLite` (не требует разворачивания внешних серверов БД для теста на 2–3 человека). Хранит паспорта метрик, историю наблюдений (для расчета личного коридора нормы $Baseline_{personal} - 2\sigma$), задачи с когнитивным профилем, элементы стратегии, личные эксперименты и журнал аудита вызовов агента.
* `engine.py` — Математическое ядро системы:
  * Расчет индекса устойчивости $SGI = CurrentLevel \times (Stability / 10)$ и узкого горлышка по закону Либиха.
  * Каскадные шлюзы (`LOCKED`, `RESTRICTED`, `UNLOCKED`) и механизм **Информированного согласия (Soft Gating)** с расчетом мультипликаторов риска (рост вероятности ошибки, растяжение сроков, дни отката).
  * Вероятностный **Детектор конгруэнтности ($D$-Index)** и генератор «Сократических уколов» с 10-минутным микро-контрактом.
  * Командный агрегатор **Zero-Knowledge Team Extension** и режим **Корпоративного интенсива** с принудительным буфером восстановления.
* `knowledge_base.py` — Встроенная база доказательных рекомендаций **HowToLiveBetter** (с паспортами доказательности Grade A/B и противопоказаниями) + каталог внешних возможностей (**Opportunity Radar** для грантов и научных хабов).
* `agent.py` — **Главный Агент (Мета-Оркестратор)** с реестром из 12 инструментов (`Function Calling Schema`). Работает как с внешними LLM (`OpenAI`, `DeepSeek`, `OpenRouter`), так и во встроенном автономном режиме без платных ключей.
* `bot.py` — Сервер Telegram-бота и интерактивная CLI-консоль со всеми командами (`/start`, `/checkin`, `/status`, `/tasks`, `/strategy`, `/experiment`, `/reflection`, `/stress_test`, `/smart_content`, `/second_brain`, `/team`, `/intensive`, `/export_grant`, `/chat`).
* `test_simulation.py` — Автоматический симулятор пилотного тестирования на 3 участниках команды, проверяющий все сценарии и формирующий готовый научно-технический отчет `grant_pilot_report.md`.

## 2. Быстрый запуск (3 варианта на выбор)

Система написана на чистом **Python 3.10+** с использованием стандартной библиотеки, поэтому запускается мгновенно на любом компьютере или VPS без сложной настройки окружения.

### Вариант А. Прогон симуляции пилота на 3 человека и генерация отчета для гранта
```bash
python3 test_simulation.py
```
Скрипт создаст тестовую базу, прогонит сценарии трех участников команды (срабатывание Soft Gating, детектора $D$-Index, 7-дневного эксперимента HowToLiveBetter и режима интенсива) и сохранит готовый отчет в `grant_pilot_report.md`.

### Вариант Б. Интерактивное тестирование прямо в терминале (без токена Telegram)
```bash
python3 bot.py --cli
```
Вы сразу попадаете в диалог со Штурманом DelaemOS и можете вводить любые команды (`/start`, `/status`, `/checkin 4 4 6`, `/tasks Написать главу гранта`, `/stress_test`, `/strategy`, `/team`) или общаться свободным текстом.

### Вариант В. Запуск боевого Telegram-бота для вашей команды (2–3 человека)
1. Получите токен у `@BotFather` в Telegram.
2. (Опционально) Укажите ключ OpenAI или DeepSeek для генеративных рассуждений (если ключ не указан, бот работает на встроенном кибернетическом диспетчере):
```bash
export TELEGRAM_BOT_TOKEN="ваш_токен_от_BotFather"
export LLM_API_KEY="ваш_ключ_openai_или_deepseek"
export LLM_BASE_URL="https://api.openai.com/v1" # или https://api.deepseek.com/v1
python3 bot.py
```

## 3. Как использовать результаты в заявке на грант (ФСИ «Студенческий стартап» / «Старт-1»)

1. Запустите бота на 7–14 дней для вашей команды из 2–3 человек.
2. Каждое утро выполняйте 30-секундный `/checkin`, добавляйте ключевые задачи через `/tasks`, проверяйте сопротивление через `/stress_test` и запустите по одному микро-эксперименту `/experiment`.
3. В конце тестового периода вызовите команду `/export_grant` — бот автоматически выгрузит таблицу телеметрии группы, количество предотвращенных когнитивных перегрузок (`Soft Gating`), статистику вызовов инструментов Главного Агента и динамику $SGI$ для включения в раздел «Научно-техническая новизна и результаты предварительных испытаний».
